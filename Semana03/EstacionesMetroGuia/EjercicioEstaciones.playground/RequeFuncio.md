# Requerimientos funcionales – MetroGuía Lima

## Descripción del sistema

**MetroGuía Lima** es un sistema desarrollado en Swift que se ejecuta mediante la consola de macOS. Su propósito es orientar a los usuarios sobre las líneas, estaciones, rutas y lugares cercanos del Metro de Lima.

## Requerimientos funcionales

### RF01 – Mostrar el menú principal

El sistema debe mostrar un menú principal con las opciones disponibles para el usuario.

### RF02 – Almacenar las estaciones

El sistema debe almacenar las estaciones correspondientes a las líneas 1, 2, 3 y 4 del Metro de Lima.

### RF03 – Normalizar los nombres ingresados

El sistema debe aceptar nombres escritos con mayúsculas, minúsculas, con tildes o sin tildes.

### RF04 – Explorar la información de las líneas

El sistema debe permitir consultar las líneas, estaciones, horarios y tarifas disponibles.

### RF05 – Identificar la línea de una estación

El sistema debe identificar la línea o las líneas a las que pertenece una estación determinada.

### RF06 – Calcular rutas directas

El sistema debe calcular una ruta directa cuando la estación de origen y la estación de destino pertenezcan a la misma línea.

### RF07 – Indicar la dirección del tren

El sistema debe indicar la dirección correcta del tren que el usuario debe tomar para llegar a su destino.

### RF08 – Calcular rutas con cambio de línea

El sistema debe calcular rutas que requieran realizar uno o más cambios de línea.

### RF09 – Utilizar estaciones oficiales de conexión

El sistema debe utilizar las estaciones oficiales de conexión para realizar los cambios entre líneas.

### RF10 – Seleccionar la conexión más corta

El sistema debe seleccionar la conexión que permita recorrer la menor cantidad de estaciones.

### RF11 – Calcular el tiempo del recorrido

El sistema debe calcular y mostrar el tiempo aproximado que tomará el recorrido.

### RF12 – Buscar un lugar por su nombre

El sistema debe permitir que el usuario busque un lugar conocido ingresando su nombre.

### RF13 – Mostrar lugares similares

El sistema debe mostrar las coincidencias encontradas cuando existan varios lugares con nombres parecidos.

### RF14 – Buscar lugares por categoría

El sistema debe permitir la búsqueda de lugares según la categoría seleccionada por el usuario.

### RF15 – Recomendar una estación

El sistema debe recomendar la estación más conveniente para llegar al lugar seleccionado.

### RF16 – Mostrar lugares relacionados con una estación

El sistema debe mostrar los lugares conocidos que se encuentran relacionados o cercanos a una estación.

### RF17 – Mostrar la dirección del lugar

El sistema debe mostrar la dirección correspondiente al lugar seleccionado.

### RF18 – Finalizar el programa

El sistema debe finalizar correctamente cuando el usuario seleccione la opción de salir.

### RF19 – Mostrar horarios y tarifas

El sistema debe mostrar en una misma consulta los horarios y las tarifas correspondientes a todas las líneas.
